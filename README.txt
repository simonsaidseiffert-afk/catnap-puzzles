CATNAP PUZZLES v1.0 — iPhone Home Screen App

1. Upload EVERY file in this folder to a static HTTPS website (GitHub Pages, Cloudflare Pages, or Netlify). Keep them in the same folder.
2. Open the resulting URL in Safari on each iPhone.
3. Tap Share → Add to Home Screen → enable Open as Web App (if offered) → Add.
4. Open the installed app once online; it can subsequently launch offline.

Opening index.html as a local file on iPhone does not install a PWA: service workers require HTTPS (or localhost).

Progress and records are stored per device and browser profile. Existing records from local HTML files may not migrate to the hosted version automatically.

The app contains no ads or trackers.
